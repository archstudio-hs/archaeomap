🗃️ 유적 DB

국가유산청, 일본 국토수치정보, UNESCO, Wikidata, OpenStreetMap, Pleiades를 모은 약 10만 곳. 검색할 때 실시간 자료도 함께 찾아요.

클릭하면 다음 화면

되는 것 유적 검색(통합 DB 약 10만 곳 + 실시간 자료), 구글 지도 좌표 붙여넣기, 그룹별 기호·번호·유적명, 표준·흑백·위성·등고선 지도와 음영기복, 범례·캡션·고도 범례, 여백 설정, 유물 사진 연결, SVG·PNG·JPG·TIFF·PDF 출력.

안 되는 것 모바일이랑 태블릿, 수정·재배포·상업적 이용(PolyForm Strict).

  1. .zip을 풀어요.

다운로드 →

도움말

보안 경고가 뜨는 이유

Windows·macOS용 프로그램에는 코드 서명이 없어서, 내려받거나 처음 실행할 때 경고가 뜰 수 있어요. 학교·기관 컴퓨터에서 실행이 막히면 웹 버전을 쓰면 돼요.

Windows에서 “Windows의 PC 보호”가 뜰 때

추가 정보 → 실행을 눌러요. Smart App Control이나 기관 정책으로 막힌 경우엔 웹 버전을 쓰면 돼요.

macOS에서 실행이 막힐 때

시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 눌러요. “손상되어 열 수 없습니다”라고 뜨면 먼저 다시 내려받아 보고, 그래도 같으면 출처를 확인한 뒤 터미널에서 아래를 실행해요.

xattr -dr com.apple.quarantine "/Applications/ArchaeoMap.app"
검색에 없는 유적을 넣으려면

검색창 아래 등록 안 된 유적 추가를 누르고, 구글 지도에서 유적 자리를 오른쪽 클릭해 맨 위 숫자(예: 34.462575, 135.806446)를 복사해 붙여넣어요. 중국 본토는 꼭 위성 보기에서 찍어요.

다른 컴퓨터에서 이어서 하려면

웹 버전과 설치형 프로그램은 자동 저장이 따로예요. 맨 위 저장으로 프로젝트 파일을 받고, 옮겨 간 곳에서 프로젝트 → 프로젝트 열기로 열면 돼요.
